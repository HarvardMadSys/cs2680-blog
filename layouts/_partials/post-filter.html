{{/* Filter for a long list of posts. Takes a dict: `pages`, the whole collection the list is paginated from, and `noun` for the count. The list below this box shows one page of twenty. The filter searches all of them, which is the point of it -- a filter that only searched the twenty in front of you would tell a student their classmate's post does not exist. So every post's card is rendered once here into a JSON island and the matches are swapped into the list when a query is typed. The cards come from post-card.html, the same partial the page itself uses, so a filtered card cannot drift from an unfiltered one. At eighty posts the island is about 7 KB gzipped, which is cheaper than the figures in any one post. The box stays hidden without JS, because without JS it would be a box that does nothing. */}} {{- $noun := or .noun "posts" }} {{- $pages := .pages }}
{{- $index := slice }} {{- range $pages }} {{- $index = $index | append (dict "f" (lower (printf "%s %s %s" .Title (delimit (or .Params.authors slice) " ") (delimit (or .Params.tags slice) " "))) "h" (partial "post-card.html" . | string)) }} {{- end }} {{/* safeJS, because html/template otherwise escapes the JSON a second time as a JavaScript string literal and JSON.parse then hands back a string rather than an array. jsonify already escapes < > and & to \u003c and friends, so no card's markup can close this script element early. */}}
